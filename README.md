# meowerhub

A multi-purpose discord bot tailored to the meower's hub discord server.

code is pretty crappy but if it works it works
adapt it to your servers if you'd like but this is designed for one server and one server only
only one locale for now

---
# Usage

Compile the native binary with the following command
```
$ make
```

And run the bot with
```
$ python main.py # or ./main.py
```
